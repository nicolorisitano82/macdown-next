What it does

The short version. The guide has all of it, feature by feature, including what each one deliberately refuses to do.

The editor

It draws the Markdown

Markers disappear until the caret reaches them. Lists get a hanging indent, quotations a rule down the margin, headings room above. Tables are edited by command, and their columns are drawn in the preview, which has the room for them.

None of it touches the file: what you save is the string you typed, to the character.

Diagrams

Mermaid 11, Graphviz, draw.io

Mermaid 11.17 up from 8.4.3, Graphviz with six layout engines, and zoom and pan on any diagram — the zoom survives a refresh, so you keep your place while typing.

The draw.io importer turns every page of a .drawio file into a PNG beside the document, with 97 shape libraries inside the plug-in: it draws with no connection at all.

Exporting

Files that survive the trip

HTML, PDF, EPUB 3.3, and Word that arrives with its tables as tables, its lists indented and its code monospaced on Windows too — AppKit's own writer loses all three.

Diagrams are drawn into every export, rather than shipping the source and hoping the reader runs JavaScript.

Textbundle and Textpack as well — the Markdown as written with its pictures beside it, in somebody else's format on purpose — written and read alike.

In the Finder

Press space, read the document

A Quick Look extension renders .md files with the same style sheet the app opens with. Pictures beside the document travel with the preview; the page itself cannot reach the network.

Diagrams and formulas are drawn there too — mermaid, all six Graphviz engines, TeX through MathJax — and [[WikiLinks]] are links, marked when the page they point at is not there yet.

A panel in the preferences says whether macOS has it, which copy is providing it and which version — and installs, updates or removes it, because that registration goes wrong quietly.

The two panes

One selection, in both

Select words in the preview and the same words are selected in the source, with the focus there: delete removes them, typing replaces them. Select a sentence in the editor and the page marks it.

Which words, exactly, is the whole problem — the rendered text is not the source. The second test of a paragraph is the second one, and a selection that cannot be placed with certainty leaves the editor alone and says so.

Writing

A prose checker, and help that runs here

Qualifiers, weasel words, hedging, wordiness, passive tells and repeated words, in English and Italian, with a panel that lists them and takes you to each one.

Improve, correct, make formal, plain, shorter, longer — over a selection or a paragraph, from a model running on your Mac through llama.cpp. Nothing is sent anywhere.

Collecting

A folder you can navigate

[[Wiki links]] between neighbouring documents, and a list of which documents point at this one, with the line and the sentence around it.

Save a web page as Markdown beside your notes, with the address and the date at the top: a clipping without its source is a quotation without a source.

Agents

A folder an assistant can read

macdownext-mcp, inside the application, hands one declared folder to Claude Code, Claude Desktop or any other MCP client over a pipe: search it, read a file, list what is there, see a document's outline, ask who cites a document or which notes declare a field. The application does not have to be running.

And nothing else. No tool writes, renames or deletes; a path that leaves the folder is refused; a second folder is an error rather than a second permission.

What changed, concretely

This fork exists because of specific things that did not work. These are five of them.

Before

Graphviz replaced the whole page body with the first graph it drew, taking the rest of the document with it, and stopped redrawing after the first keystroke.

Now

Six layout engines, each its own fence language, redrawn as you type, zoomable, and following the system appearance.

Before

A Word export dropped the pictures, flattened tables into tab-separated paragraphs, lost list indentation, and named a Mac-only font with nothing to substitute it.

Now

Each of those is repaired in the file afterwards, and remote pictures are fetched into the package first, so the document opens whole on somebody else's computer.

Before

Finder showed the source of a Markdown file — hashes, asterisks and all — and there was no way to know whether a preview extension was even registered.

Now

Space renders the document — diagrams and formulas drawn, WikiLinks as links — and a preferences pane says where the extension stands and fixes it in one click.

Before

The preview was a page you could only read: selecting a sentence in it told the editor nothing, and finding those words in the source was your problem.

Now

The two panes share one selection, either way round. Delete on a selection made in the preview takes those words out of the source; a selection that cannot be placed with certainty leaves the editor alone and says so.

Before

A new version existed only if you went looking for it, and the editor coloured ##Titolo as a heading while the preview drew it as a paragraph.

Now

The app looks once a day and asks three times before doing anything, and both parsers agree about what a heading is — with a one-click fix when the space is missing.
